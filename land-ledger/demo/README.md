## Demo flow (10 acts)

1. Public face — landing, features, how-it-works
2. Sign-in and MFA — login + OTP
3. The citizen's world — dashboard, properties, detail tabs
4. On-ramp/new-lands — register property form
5. The citizen's vault — documents, transfers, ledger
6. Multi-party consent — TRF-2026-0001 approve flow
7. Surveyor on the ground — field inspection, verification
8. The verification desk — clerk scrutiny, hash check, document view
9. Registrar and the ledger — approval, on-chain seal
10. Institution oversight — admin control tower, audit trail, dark mode morph
