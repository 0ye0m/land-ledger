27. FRAUD / CONFLICT ENGINE
============================================================

Implement a dedicated RULE-BASED FRAUD AND CONFLICT CHECKING ENGINE.

Do not label it AI unless an actual ML model exists.

Required checks:

1. Multiple active transfer requests for the same property.

2. Transfer requested while another transfer remains pending.

3. Requested seller is not current owner.

4. Property does not exist.

5. Property is in conflicting/invalid state.

6. Document hash mismatch.

7. Transfer requested after ownership already changed.

8. Any additional deterministic consistency checks that are directly relevant to ownership transfer.

Return:

isFraudulent
riskLevel
reasons
checksPerformed

Example:

{
  "isFraudulent": true,
  "riskLevel": "HIGH",
  "reasons": [
    "Another transfer request already exists for this property",
    "Requested seller is not the current owner"
  ]
}
